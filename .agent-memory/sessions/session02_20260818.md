### 2. voted 화면 2×2 그리드 순서 수정
- **파일**: `src/app/today/page.tsx`
- **원인**: `GRID_POS` 배열에서 3번(인덱스2)=좌하, 4번(인덱스3)=우하였는데 화살표는 시계방향(좌상→우상→**우하→좌하**)
- **수정**: `GRID_POS` 3번=우하, 4번=좌하로 교정 → 화살표 방향과 일치
- `key={id}` → `key={i}` 로 변경 (인덱스 기반)

### 3. 룰렛 같은 결과 반복 버그 수정
- **파일**: `src/components/RouletteWheel.tsx`
- **원인**: `rotation` 값이 스핀마다 누적(2340→4680→...)되면서 같은 칸으로 수렴
- **수정**: `const currentNorm = rotation % 360` 으로 정규화 후 계산
- 룰렛 설계: 돌릴 때마다 새로 랜덤 (오늘 1회 고정 아님)

### 4. 빌딩 캐릭터 확대 모달

### 5. 스카이라운지 텍스트 개선

### 6. 좋아요/싫어요 분리 표시 (백엔드 + 프론트 동시 수정)
- **Lambda `wash-vote`**: 투표 시 `likes` 또는 `dislikes` 카운터 DynamoDB에 별도 저장
  - `UpdateExpression`: `"ADD score :delta, likes :one"` / `"ADD score :delta, dislikes :one"`
- **Lambda `wash-getRankings`**: `likes`, `dislikes` 필드 함께 반환
- **`src/lib/api.ts`**: 타입에 `likes`, `dislikes` 추가
- **`src/app/building/page.tsx`**: 👍/👎 pill 분리 표시, 내 층도 포함
- **기존 데이터 백필**: wash-votes 테이블에서 집계 → wash-rankings에 직접 업데이트
  - hair-body-face-teeth: likes=2
  - body-teeth-hair-face: likes=2
  - body-hair-face-teeth: likes=1
  - teeth-hair-body-face: likes=1
  - body-face-teeth-hair: dislikes=1
  - body-teeth-face-hair: dislikes=1

## 핵심 결정사항
- 룰렛은 **돌릴 때마다 새로 랜덤** (오늘 1회 고정 아님)
- 빌딩 층수 순위 기준: `score = 좋아요×2 - 싫어요×1`
- 좋아요/싫어요는 분리 표시 (👍 N / 👎 N)
- 기존 투표 데이터는 wash-votes 테이블에서 역산해 백필 완료
