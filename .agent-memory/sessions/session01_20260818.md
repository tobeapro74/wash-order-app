- **원인**: 카카오 콘솔에서 Client Secret ON 상태이나 요청에서 누락/빈 값 전송
- **수정 과정**:
  1. `process.env.KAKAO_CLIENT_SECRET` 환경변수 사용
  2. Amplify 환경변수 설정
  3. 웹 플랫폼 도메인 미등록 → 카카오 콘솔에서 등록
  4. Client Secret → **OFF** 로 변경 후 재배포로 최종 해결
